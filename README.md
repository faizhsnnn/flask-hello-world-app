## Flask Hello World App

This project demonstrates how to create a basic web application using the Flask framework in Python.

The application initializes a Flask server and defines a simple route that returns a "Hello World" response when accessed through the browser.

This project serves as an introduction to building web applications with Flask and understanding how routing works in a backend web framework.

This project was built as part of the #90DaysOfCode challenge to practice backend development and web server fundamentals using Python.

---

## Technologies Used

Python  
Flask

---

## Key Concepts Demonstrated

Creating a web server using Flask

Defining routes using Flask decorators

Handling HTTP requests in a Flask application

Running a development server locally

Understanding the basic structure of a Flask application

---

## Application Workflow

1. Import the Flask framework
2. Create a Flask application instance
3. Define a route for the homepage
4. Return a response when the route is accessed
5. Run the Flask development server

---

## Installation

Install Flask

```
pip install flask
```

---

## Run the Application

```
python main.py
```

Once the server starts, open your browser and navigate to:

```
http://127.0.0.1:5000
```

You should see the message:

```
Hello World
```
